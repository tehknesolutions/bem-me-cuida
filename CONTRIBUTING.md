# Contribuição

## Fluxo

1. Abra uma branch `feat/`, `fix/`, `docs/` ou `chore/`.
2. Faça mudanças pequenas e revisáveis.
3. Atualize testes e documentação.
4. Execute `npm run check`.
5. Abra PR para `main` com riscos, evidências e plano de rollback.

## Convenções

- TypeScript estrito, sem `any` não justificado.
- Componentes acessíveis e com alvos de toque adequados.
- Nenhuma linguagem diagnóstica na interface.
- Nenhum dado sensível em fixtures, commits ou logs.
- Assinatura institucional apenas da Tehkné Solutions.
